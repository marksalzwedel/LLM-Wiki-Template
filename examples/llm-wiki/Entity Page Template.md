# Entity Page Template

## Summary

State what the entity is in one or two sentences. Keep this portable enough that another paper can reuse the page without rewriting the whole thing.

## Explanation

Explain how the entity works, why it matters, and where it appears in the source material. Prefer concrete relationships to vague importance claims.

## Related Links

- Use bracket links such as [[Alignment]], [[BERT]], and [[Contradictions Between Papers]].

## Source Papers

- Link the papers that define, use, challenge, or extend the entity.

## Contradictions and Tensions

- Note direct contradictions, later revisions, scope changes, or evaluation mismatches between papers.
- If there is no direct contradiction, say what the closest tension is.
