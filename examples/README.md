# Examples

This folder contains completed example material that demonstrates the template output.

- `llm-raw/` contains the original example source PDFs.
- `llm-wiki/` contains the generated Obsidian-style LLM wiki.

Do not use these folders as the active project workspace unless you are intentionally studying or modifying the example. For a new project, put active source files in `raw/` and active notes in `wiki/`.
