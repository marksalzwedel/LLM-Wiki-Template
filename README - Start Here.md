# Start Here

This folder is a copyable Codex plus Obsidian project template. If you found it
in a read-only SharePoint template library, copy the whole folder into your own
SharePoint-synced workspace before editing anything.

## Create Your Project

1. Copy this whole folder.
2. Paste the copy into your own SharePoint-synced project area.
3. Rename the copied folder to your project name.
4. If your company uses OneDrive Files On-Demand, right-click the copied project
   folder and choose **Always keep on this device**.
5. Open the copied top-level folder in Codex.
6. Open the copied `wiki/` folder in Obsidian if you want a note-taking view.

Do not edit the read-only master template directly. Work only in your copied
project folder.

## Where Things Go

```text
raw/       Put project source files here.
wiki/      Codex and Obsidian notes live here.
examples/  Reference material only.
scripts/   Health-check and maintenance helpers.
```

## Sharing Checklist

- Confirm the copied project is in the intended SharePoint or Teams location.
- Check who has access before adding confidential or restricted source files.
- Use your company's normal SharePoint permission process for sensitive work.
- Keep source files in `raw/` and project notes in `wiki/`.
